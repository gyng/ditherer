# 072 — Simulation and artistic crossovers

## Objective

Add four WebGL2 filters that balance mechanism-driven simulation with expressive
image treatment while remaining distinct from the existing catalog:

1. **Schlieren Optics** — directional knife-edge, color-schlieren, and
   shadowgraph views of source-luminance gradients.
2. **Laser Speckle Projector** — coherent interference grain modulated by the
   projected image, with scan structure and physically motivated diversity.
3. **Suminagashi Marbling** — concentric ink rings advected and combed by a
   source-derived flow field over textured paper.
4. **Quasicrystal Mosaic** — source-modulated, non-periodic facets generated by
   five-, seven-, eight-, or ten-fold plane-wave interference.

## Research basis

- Schlieren imaging converts refractive deflection into brightness by blocking
  part of a focused source with a knife edge. Its sensitivity is directional:
  horizontal and vertical knife edges reveal orthogonal density gradients;
  color schlieren encodes deflection direction chromatically.
- Fully developed coherent speckle is an intensity pattern produced by a
  random walk of complex amplitudes. Its contrast is unity for one mode and
  falls as `1 / sqrt(M)` when `M` independent intensity patterns are averaged.
- Optical induction experiments form photonic quasicrystals from multiple
  interfering plane waves, including rotational symmetries forbidden in
  periodic crystals.
- Suminagashi is represented as an artistic fluid analogue: nested deposited
  rings are transported by a divergence-free source-derived flow and combed
  before being laid onto a fibrous paper field. It is intentionally an
  expressive model rather than a quantitative fluid solver.

## Implementation

1. Add pure mechanism helpers for knife-edge gradient projection, speckle
   diversity contrast, and evenly distributed quasicrystal wave directions.
2. Protect those helpers and the four catalog contracts with focused tests.
3. Implement one source-backed GLSL pass per filter with bounded loops,
   opaque output, described controls, and no redundant JavaScript fallback.
4. Register the filters, regenerate catalog artifacts, and run the real
   Chromium WebGL2 branch/draw gate.
5. Review all four defaults in the application against a photographic fixture,
   tune hierarchy and legibility, then repeat shader and full-suite validation.

## Acceptance gates

- Knife-edge response changes sign when the gradient reverses and vanishes for
  a gradient parallel to the edge.
- Speckle diversity reduces contrast monotonically according to `1 / sqrt(M)`.
- Quasicrystal orders generate unique, evenly spaced wave directions.
- Every filter is `requiresGL`, worker-resolvable, and fully described.
- All enum branches compile and draw without transparent, black, or flat
  default output.
- Focused tests, generated-registry checks, typecheck, lint, production build,
  the complete GL gate, and application-level visual review pass.

## Outcome

Implemented and registered all four filters as WebGL2-only catalog entries.
Three application-level visual passes corrected over-frequency projector grain,
thin and uneven marbling coverage, and excess fine-texture response in the
schlieren default. A final source audit also removed reversed-edge `smoothstep`
calls and aligned quasicrystal highlights with actual terrace boundaries.

Final validation passed 1,894 unit/integration tests, 2,578 Chromium GPU
profiles across 712 shader compiles and 8,343 draws, focused mechanism and
registry contracts, lint, typecheck, generated-registry verification, library
type generation, and both production builds with the application chunk budget
intact.
